# piper_wrist_cam_mount

An AgileX Piper arm camera mount — a Piper arm camera mount / Piper wrist camera mount that takes the Intel RealSense D435, D435i, and D405 interchangeably. It is a modified version of kai0's "end-effector-camera-mount-d435i-centered.STEP" work.

## Files

| File | Format | Description |
| --- | --- | --- |
| `[piper][26.08.15]ee-cam-mount-d435_d405-centered_fianl.step` | STEP | Full assembly drawing (complete model) |
| `[piper][26.08.15]ee-cam-mount-d435_d405-centered_final.3mf` | 3MF | Print project with the parts pre-arranged; printing in the orientation as set gives the best results |
| `[piper][26.08.15]ee-cam-mount-d435_d405-centered_part1.stl` | STL | Split part 1, ready for 3D printing |
| `[piper][26.08.15]ee-cam-mount-d435_d405-centered_part2.stl` | STL | Split part 2, ready for 3D printing |

- Files ending in `_part`: the model split into separate parts for 3D printing (STL)
- `.step` file: the full drawing — the complete source geometry for editing/modification

## Assembly Guide

### Required Hardware
- M3x6mm screws x2
- M3x11mm bolts x2
- M3 nuts x2
- M5x40mm bolt x1
- M5 nut x1
