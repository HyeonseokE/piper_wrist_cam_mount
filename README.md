# piper_wrist_cam_mount
wrist camera mount for piper( intel realsense D435, D435i, D405)
modified version of kai0's "end-effector-camera-mount-d435i-centered.STEP" work

## Files

| 파일명 | 포맷 | 설명 |
| --- | --- | --- |
| `[piper][26.08.15]ee-cam-mount-d435_d405-centered_fianl.step` | STEP | 전체 도면 (조립 상태 전체 모델) |
| `[piper][26.08.15]ee-cam-mount-d435_d405-centered_part1.stl` | STL | 출력용으로 나눠놓은 파츠 1 |
| `[piper][26.08.15]ee-cam-mount-d435_d405-centered_part2.stl` | STL | 출력용으로 나눠놓은 파츠 2 |
